# 🎒 Məktəbə Hazırlıq Proqramı

> **5-6 yaş uşaqları üçün interaktiv məktəbəqədər hazırlıq platforması**  
> Azərbaycana uyğunlaşdırılmış 2 aylıq tədris proqramı

---

## 📋 Xüsusiyyətlər

- 🌐 **3 dil dəstəyi** — Azərbaycan 🇦🇿 | Rus 🇷🇺 | İngilis 🇬🇧
- 👑 **Admin Panel** — sistem idarəetməsi, statistika
- 👩‍🏫 **Müəllim Paneli** — gündəlik qeyd, qiymət, davranış
- 👦 **Uşaq Profili** — fərdi tərəqqi izləmə
- 📅 **2 Aylıq Tədris Planı** — 8 həftə, 5 gün/həftə
- 📊 **Avtomatik Hesabat** — qrafik və statistikalarla
- 🎮 **İnteraktiv Məşğələlər** — şəkillərlə izahlı

---

## 🚀 Qurulum

### Backend
```bash
cd backend
npm install
cp .env.example .env
# .env faylında MONGO_URI dəyişdirin
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```
