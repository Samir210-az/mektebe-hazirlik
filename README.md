## 🌟 Platforma Haqqında

**Məktəbə Hazırlıq** — Azərbaycanda 5-6 yaşlı uşaqları məktəbə hazırlamaq üçün yaradılmış rəqəmsal tədris platformasıdır. 8 həftəlik proqram çərçivəsində uşaqlar **9 fənn** üzrə interaktiv dərslər keçir, müəllimlər isə gündəlik qeydlər aparır, valideynlər tərəqqini izləyir.

---

## ✨ Əsas Xüsusiyyətlər

### 🎓 Tədris

| Xüsusiyyət | Təsvir |
|---|---|
| 📚 **13+ İnteraktiv Məşğələ** | Real məzmunlu, şəkilli, addım-addım dərslər |
| 📅 **8 Həftəlik Plan** | Hər həftənin mövzusu, günlük dərs cədvəli |
| 9 Fənn | Riyaziyyat, Az. Dili, Oxu, Rəsm, Musiqi, Bədən T., Təbiət, Məntiq, Yaradıcılıq |
| 🌍 **3 Dil** | Azərbaycan 🇦🇿 · Rus 🇷🇺 · İngilis 🇬🇧 |

### 👥 Rol Sistemi

| Rol | İmkanlar |
|---|---|
| 👑 **Admin** | İstifadəçi idarəetməsi, tam sistem nəzarəti, statistika |
| 👩‍🏫 **Müəllim** | Gündəlik qeyd, qiymət, davranış, uşaq profili |
| 👨‍👩‍👦 **Valideyn** | Elanlar, tədris planı, məşğələlər |

### 📊 Qeyd & Hesabat Sistemi

- ⭐ Hər fənn üzrə **1-10** qiymət
- 😊 **Davranış** qiymətləndirməsi (Əla / Yaxşı / Qənaətbəxş / Yaxşılaşdır.)
- 🎯 **Diqqət, Fəallıq, Əməkdaşlıq** ulduz reytinqi (1-5)
- 📈 Həftəlik tərəqqi qrafiki
- 📋 Fənn üzrə progress barlar
- 📨 Valideynə mesaj

## 📚 Tədris Proqramı (8 Həftə)

| Həftə | Mövzu | Əsas hədəflər |
|:---:|---|---|
| 1️⃣ | Tanışlıq və Məktəb | A, B, V hərfləri · 1-3 rəqəmləri · Rəsm |
| 2️⃣ | Ailə və Sevgi | G, D hərfləri · 4-5 rəqəmləri · Nağıl |
| 3️⃣ | Təbiət və Heyvanlar | E hərfi · 6-10 topla/çıx · Kağız sənəti |
| 4️⃣ | Rənglər və Fiqurlar | Z, J, Y · 1-10 sayma · Kollaj ✅ |
| 5️⃣ | Azərbaycan — Vətənimiz | Vətən sevgisi · 1-20 rəqəmlər · Bayraq |
| 6️⃣ | Peşələr | Rol oyunu · Pul anlayışı · Peşə rəsmi |
| 7️⃣ | Riyaziyyat Dünyası | Onluqlar · Ölçmə · Saat · Yarış |
| 8️⃣ | Məzuniyyət 🎓 | Bütün hərflər · 1-20 · Portfolio · **Hazırsınız!** ✅ |
